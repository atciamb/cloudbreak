Wiring: one servo, powered by the UNO Q

  • One servo at a time. Unplug that servo's lead from the FC first so the board's 5V can't back-feed the FC servo rail. Flight battery stays disconnected; give Iain a heads-up (power rule).
  • The servo plug and the UNO Q headers are both female: use 3 male-to-male jumpers. Wire colours: signal orange/yellow/white, + red, − brown/black.
  • If the UNO Q resets or the servo stutters when it moves, the USB port is short of current: use a stronger USB-C port or supply, keep the surface free, don't hold it against a stop.
  • D9 outputs 3.3 V logic, which hobby servos accept.

        First-time setup (Arduino IDE 2)
        
    
          
  1. Open tools\servo_bench\servo_bench_d9\servo_bench_d9.ino in the Arduino IDE.
    2. 
          
  2. Tools › Board › Arduino UNO Q Board › Arduino UNO Q, port COM3. Not "Arduino Uno".
    3. 
          
  3. Library Manager: install Arduino_RouterBridge (choose "Install all"), and make sure Servo is 1.3.0 or newer.
    4. 
          
  4. Upload. The servo centres right away; the USB link comes up once the board's Linux side has booted (up to a minute after power-up).
    5. 
          
  5. Close the IDE's Serial Monitor (it holds COM3), then press Connect UNO Q here and pick the UNO Q port.
    6. 
          
  6. No reply? Press Other port… and choose COM3, or type commands in the IDE Serial Monitor instead (line ending "New Line").
